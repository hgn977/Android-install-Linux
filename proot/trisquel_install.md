## 安装Trisquel环境

1. 安装 proot-distro
```
pkg update
```
```
pkg install proot-distro
```
2. 安装 Trisquel
```
proot-distro install trisquel
```
3. 登录 Trisquel
```
proot-distro install trisquel
```
